# QR-Based Membership Card Automation

A real-world Google Apps Script automation project that streamlines the generation and management of QR-enabled membership cards. The system automates the complete workflow from member registration to PDF card generation using Google Workspace services.

## Project Overview

This project was developed for the **Character Building Society (CBS), Nishtar Medical University** to eliminate the manual process of creating membership cards. It automatically generates unique member IDs, creates QR-enabled double-sided membership cards, exports them as PDFs, and stores them in Google Drive.

## Features

- Automated membership card generation
- Unique Member ID generation
- QR code generation
- Double-sided membership cards
- PDF export
- PDF versioning
- Card regeneration
- Google Drive integration
- Google Forms integration
- Google Sheets automation
- Google Slides template engine

## Tech Stack

- Google Apps Script
- JavaScript
- Google Forms
- Google Sheets
- Google Slides
- Google Drive
- REST API

## Workflow

1. Member submits the registration form.
2. Data is stored in Google Sheets.
3. Google Apps Script processes the submission.
4. A unique Member ID is generated.
5. A QR code is created.
6. Member information is inserted into a Google Slides template.
7. A double-sided membership card is exported as a PDF.
8. The PDF is stored in Google Drive.
